# 水产加工得率结算

核算跨境水产原料在分级和深加工后的真实得率与应付价款。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括东盟水产供应商、广西加工企业、车间质量人员、采购财务人员。

资料所依据的领域事实如下：

- 大会关注水产数字加工和跨境流通
- 现场项目涉及跨境采购与水产深加工
- 目标链路连接东盟产地、广西集散和中国市场

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
