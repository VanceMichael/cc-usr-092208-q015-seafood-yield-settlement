# 水产加工得率结算

核算跨境水产原料在分级和深加工后的真实得率与应付价款。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括东盟水产供应商、广西加工企业、车间、财务和管理层。

## 数量链

采购按到厂毛重暂估价款，分级、解冻和深加工后形成多个成品与损耗。资料按以下环节保持数量关系，任何一环只留最后净重都会让价格调整和质量争议无法复算：

采购合同 → 到货称重 → 抽样品质 → 加工工单 → 分级产物 → 副产物 → 合理损耗 → 成品交付

## 受控事件

跨班次投料、混批、复称更正、部分拒收、委外加工和币种换算必须双人确认并保留版本记录。

## 核对视角

- 供应商：核对与自身批次有关的扣价依据
- 车间：看到可执行配料
- 财务：结算时证明每个数量和金额的来源
- 管理层：比较不同原料、产线与工艺的真实得率

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、数量链、受控事件、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
